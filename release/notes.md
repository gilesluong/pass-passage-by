## Scan, review and teach

- Preserves the startup safety, native sidebar, card buttons and appearance improvements from the Antigravity handoff.
- Scan photo/PDF, paste screenshots, and receive Continuity Camera images through native macOS menus.
- Review source pages beside offline Apple Vision OCR, then create an essay, append text or use it as a task prompt.
- My writing auto-saves a local document library, with a list and reading preview.
- Optional on-device Apple Intelligence generates anchored, editable annotation suggestions when its model is available. No automatic AI-model downloads.
- Sparkle is the single update channel; stable app name, bundle ID and draft path are retained.

Apple Silicon, macOS 13+. Apple Intelligence requires macOS 26+ and an available system model. OCR may misread handwriting, columns or charts; review the text against the source. Development preview: Sparkle Ed25519-signed archive; app is not Apple-notarized.
