# Pass Passage By!

Native macOS writing, semantic zoom and margin annotations.

This repository distributes app releases and the Sparkle appcast. After installing the initial Sparkle-enabled app, use **Pass Passage By! → Check for Updates**.

Requirements: Apple Silicon, macOS 13 or later. Current builds are development previews: ad-hoc Apple code signature, cryptographically signed Sparkle archives, not Apple-notarized.

Stable app identity: `com.passage.editor`. This repository does not include user essays or app source.
